# Documentation Archive

This directory preserves historical planning and report documents that are no longer the current operating guide.

## Why these files were archived

The project has moved past the original Prompt 1-10 and PR8-PR15 planning phases. Current documentation now lives in the root `README.md` plus the active documents indexed by `docs/README.md`, especially `docs/adk-local-workbench.md`, `docs/architecture.md`, `docs/contracts/`, `docs/operator_handoff.md`, and `docs/project-introduction.html`.

Archived files are kept for design history and traceability only. Do not use them as the current implementation checklist unless a new plan explicitly revives them.

## Archived groups

- `plans/` — historical architecture and rollout plans.
- `reports/` — historical workflow validation/reporting memos.
- `prompts/` — historical Codex implementation prompts.
- `project-plan.md` — historical Prompt/PR project status, superseded by the active workbench guide.
